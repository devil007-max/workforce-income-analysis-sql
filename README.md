📊 Workforce Income & Salary Analysis Using SQL + Power BI
A complete case study analyzing global salary trends, job roles, work modes, and experience levels using SQL & Power BI.

🧩 Project Overview

This project analyzes a global workforce dataset of salaries, job titles, experience levels, company sizes, and remote work patterns.
Using SQL + Power BI, insights were extracted to answer questions like:

Which countries pay the highest salaries?
Are remote employees paid higher?
Which job titles have the most growth?
Salary trends from 2020 to 2024
Entry-level vs Senior salary comparison
Countries with highest-paying remote jobs
